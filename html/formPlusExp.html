表单扩展

表单扩展组件formplus是对表单组件form功能的扩展。PR #1410

文件依赖

以下的功能是对模块formplus的描述,它除了需要formplus.js文件之外,还需要引用下面的内容。

css文件引用

在引用了layui.css后,还需要引用formplus.css。当然,如果是当前分支进行打包formplus.css就打包进了layui.css中,不用额外引用了

js文件引用

在引用了layui.js后,还需要注意下面模块的加入。当然,如果是当前分支进行打包就包括下面的模块了(除开第三方插件)。

  • 模块jquery
  • 模块lay
  • 模块form
  • 模块layer
  • 模块laydate可能会使用
  • 模块tree可能会使用
  • 新增模块treeorder可能会使用
  • 第三方插件lunar.js可能会使用,引入才生效

基础介绍

最开始这个功能是为了解决form.val赋值时不能触发form.on添加的change监听事件,#I5JMRW

现在通过:

  • 使用layui.formplus.on(filter, key, fn);对表单上面的属性name值为key的表单元素添加change事件,事件的回调函数会接收到change前、后的表单值
  • 再使用layui.formplus.val(filter, object);对表单进行赋值与取值
  • 最后在赋值结束后也会触发设置好的change监听事件

在使用前需要注意下面几点:

  1. 在确定使用该模块来渲染后就不能再使用layui.form.on来对表单进行change事件监听了,应该改用下面的layui.formplus.on来代替
  2. 除开上面的layui.form.on方法之外,form模块里面的所有方法和属性都还是可以使用的
  3. lay-ignore属性在这里依然适用,此外还新增了lay-formplus-ignore属性来针对formplus忽略渲染。
  4. 在formplus模块内部对于大部分表单元素(如输入框、单选框)是用字符串储存信息的;对于另外的元素(如复选框)是用数组储存信息的。如果有需要,可以使用接下来介绍的layui.formplus.getValue方法进行取值

属性与方法

表单渲染

layui.form.render(type, filter, deploy);
  • 参数type可选,对应表单组件类型,支持:input,select,checkbox,radio;这里填null,指向所有类型。
  • 参数filter可选,对应 class="layui-form" 所在元素的 lay-filter 属性值,用于指定需渲染的表单区域。
  • 参数deploy用来标记是否使用formplus来渲染表单,默认是false;使用formplus来渲染表单就要填true。

对form模块里面的render方法进行修改,在调用上新增了一个参数deploy来指定使用form模块渲染还是使用formplus模块渲染。

这样的调用方式:

  • 减少切换的代码量:在调用代码时只需增加一个参数。
  • 降低对原来代码的影响:对于原来的调用方式会直接调用form模块渲染

        layui.use('formplus', function(){

            // 防抖测试
            function debounce(isClear, fn = {}){
                if(layui.type(isClear) != 'function'){
                    if(fn._throttleID){
                        clearTimeout(fn._throttleID);
                    }
                } else {
                    debounce(true, isClear);
                    var param = {
                        context: fn.context || null,
                        args: fn.args || [],
                        time: fn.time || 300
                    };
                    isClear._throttleID = setTimeout(function () {
                        isClear.apply(param.context, param.args);
                    }, param.time);
                }
            }

            var old = layui.form.val('formplus-bth-demo1').interest;

            function changeSelect (value, oldValue){
                if(value != old){
                    layui.layer.msg('选择框 - 旧值:{' + oldValue + '}, 新值: {' + value + '}', {icon: 6});
                    console.log('选择框 - 旧值:{' + oldValue + '}, 新值: {' + value + '}');
                    old = value;
                }
            }

            // 表单渲染
            layui.form.render(null, 'formplus-form-demo1', true);
            // 表单事件监听 - 提交事件 (提交事件没有影响,只有 select,checkbox,switch,radio 这些change事件才不能混着用)
            // 这里面获取到的是form模块中的取值方法
            layui.form.on('submit(formplus-bth-demo1)', function(obj){
                var field = obj.field;
                layui.layer.msg(JSON.stringify(field), {icon: 6});
            });
            // 表单事件监听 - 使用formplus添加表单监听事件
            // 可以不用自己设置lay-filter属性,防止重复或者设置不规范
            layui.formplus.on('formplus-form-demo1','interest', function(value, oldValue){
                debounce(changeSelect, {args: [value, oldValue]});
            });
            layui.formplus.on('formplus-form-demo1','close', function(value, oldValue){
                layui.layer.msg('switch - 旧值:{' + oldValue + '}, 新值: {' + value + '}', {icon: 6});
                console.log('switch - 旧值:{' + oldValue + '}, 新值: {' + value + '}');
            });
            layui.formplus.on('formplus-form-demo1','sex1', function(value, oldValue){
                layui.layer.msg('单选框 - 旧值:{' + oldValue + '}, 新值: {' + value + '}', {icon: 6});
                console.log('单选框 - 旧值:{' + oldValue + '}, 新值: {' + value + '}');
            });
            layui.formplus.on('formplus-form-demo1','remark', function(value, oldValue){
                layui.layer.msg('文本域 - 旧值:{' + oldValue + '}, 新值: {' + value + '}', {icon: 6});
                console.log('文本域 - 旧值:{' + oldValue + '}, 新值: {' + value + '}');
            });
            layui.formplus.on('formplus-form-demo1','like', function(value, oldValue){
                layui.layer.msg('复选框 - 旧值:{' + oldValue + '}, 新值: {' + value + '}', {icon: 6});
                console.log('复选框 - 旧值:{' + oldValue + '}, 新值: {' + value + '}');
            });
            // 表单事件监听 - 普通点击事件
            $('#formplus-bth-demo1-change').on('click', function(){
                // 使用formplus修改表单
                layui.formplus.val('formplus-form-demo1', {
                    'interest': '2',
                    'close':true,
                    'sex1':'男',
                    'remark':'测试!!',
                    'like': ['write','daze']
                });
            });

            // 表单事件监听 - formplus取值
            $('#formplus-bth-demo1-val').on('click', function(){
                // 使用formplus修改表单
                // 实验性,可以直接修改表单值
                let field = layui.formplus.getValue('formplus-form-demo1');
                layui.layer.msg(JSON.stringify(field), {icon: 6});
            });
        });

新增属性

属性 - 忽略渲染(1)

lay-ignore
用法和form文档中介绍的一致,略。

属性 - 忽略渲染(2)

实验lay-formplus-ignore
这是formplus新增的忽略渲染属性,如果既想使用form进行渲染表单,又不想这个表单元素被formplus管理限制,那么添加上这个属性就可以了

属性 - 时间插件

实验laydate
标记当前输入框作为一个时间选择插件进行渲染

属性 - 补全提示

实验lay-hint
在下拉选择框中,与lay-search配合,在输入时将符合条件的 选项补全在输入后方

属性 - 输入限制

实验maxlength
输入框和文本域中 限制能输入的最大字数(这是html本身就支持的功能,这里仅添加了 显示字数的功能)

属性 - 事件限制

实验lay-lazy
输入框和文本域一般是监听input、propertychange事件,添加这个属性之后监听的是blur事件

属性 - 配置项

实验lay-options

这是从code模块借鉴来的,对于部分表单元素,可以在这个属性上设置部分配置项,从而精简js代码

请注意:lay-options属性值应为一个json字符串,里面存在引号。需要做到与属性引号的区分。示例中的demo都是区分了的,但是通过code展示时又没有区分开,统一显示成双引号。所以在复制代码后注意区分这个问题。

取值与赋值(1)

layui.formplus.val(filter, obj);
  • 参数filter必填,对应 class="layui-form" 所在元素的 lay-filter 属性值。
  • 参数obj可选,若参数存在，则对表单域进行赋值；若参数不存在，则为对表单域进行取值。

取值与赋值(2)

实验layui.formplus.getValue(filter, key);
  • 参数filter必填,对应 class="layui-form" 所在元素的 lay-filter 属性值。
  • 参数key可选,若参数不存在,则获取表单所有数据;该参数对应表单元素的name属性值,传入该参数则返回这个表单元素对应的值
  • 返回值是formplus内部维护的对象,可以在这个对象上面直接进行修改

请注意,这是一个实验性的方法,该方法会返回一个内部维护的对象,如果修改不当会出现一些意外的bug

val取值与赋值(1) 与 getValue 取值与赋值(2) 的相同点

  • 两者都可以实现表单进行赋值
  • 两者都可以实现获取表单上的值

val取值与赋值(1) 与 getValue 取值与赋值(2) 的不同点

  • val方法不传第二个参数就可以获取表单上的值,它的获取方式是调用form模块下面的同名方法
  • getValue可以直接获取formplus内部维护的对象(不是从表单上获取)
  • val方法传入第二个参数就可以表单赋值
  • getValue可以通过修改返回值来进行表单赋值

事件

layui.formplus.on(filter, key, fn);
  • 参数filter必填,对应 class="layui-form" 所在元素的 lay-filter 属性值。
  • 参数key必填,对应表单元素的name属性值,用于确定需要监听change事件的表单元素对象。
  • 参数fn必填,为事件执行时的回调函数,事件的回调函数只会接收到change前、后的表单值。

请注意,被formplus管理的表单元素就不能使用layui.form.on方法添加监听事件了。只能使用本方法来绑定change事件

layui.formplus.on具有下面几个特点

  • 表单元素都调用同一个方法,在绑定时不用来区分select、radio、checkbox
  • 输入框和文本域也可以使用本方法(默认绑定的是input、propertychange事件;在表单元素上面添加lay-lazy属性时绑定的是blur事件)
  • layui.form.on事件中允许传入表单元素的lay-filter属性来对表单元素做区分;这里建议都不要设置这个属性(没有的会自动生成),直接传入表单元素的name属性值作为区分表单元素的依据。
  • fn(value, oldValue)回调函数只传入change前后的值

水波纹

实验layui.formplus.wave(destination, option);
  • 参数destination必填,渲染的目的地
  • 参数option选填,配置项。
使用formplus渲染的表单里面符合条件的按钮都会被自动调用这个方法进行渲染。所以这个方法单独提出来为表单以外的按钮服务。

这个按钮的dom必须满足下面的结构,外面包裹一层layui-water-ripples-container为class的div(需要注意的是这个div的display是inline-block)。而参数destination指的就是这个外层div对应的jQuery对象。
<div class = "layui-water-ripples-container">
    <button class="layui-btn" >按钮</button>
</div>

参数option支持设置下面的参数,并且可以使用属性lay-options的方式在dom上进行设置:

key 描述 默认值 名称
type 类型('inset'指内波纹;'out'指外波纹) 'inset' 波纹的类型
color 16进制码或者rgba颜色 '#000000' 波纹的颜色
borderRadius 仅out类型生效,需要带上px 或者直接是填百分比 '2px' 波纹的圆角
spreadWidth 仅out类型生效,需要带上px '6px' 波纹扩展的大小
center 仅inset类型生效(true指内波纹由按钮中心扩展;false指内波纹由鼠标点击处扩展) false 波纹扩展的中心
trigger 触发方式('click'指点击触发;'mouseenter'指鼠标移入触发;'always'指总是触发) 'click' 波纹的触发方式

节假日与调休设置

实验layui.formplus.addHoliday(destination, holiday, order, work);
  • 参数destination必填,被设置日期 - 日期格式 yyyyMMdd
  • 参数holiday必填,所属节假期的日期 - 日期格式 yyyyMMdd
  • 参数order必填,节假期的序号:(0.元旦;1.春节;2.清明节;3.劳动节;4.端午节;5.中秋节;6.国庆节)
  • 参数work必填,是否调休:(true.上班;false.休息)

请注意,这是一个实验性的方法,需要搭配其它 特殊的用法才能生效。

输入框/文本域

普通的输入框是用字符串为表单值进行维护的,复选类型的下拉树使用数组为表单值进行维护

输入框/文本域事件

在上面的方法事件中就提到过:

  1. layui.formplus.on可以直接为输入框添加监听事件。
  2. 监听事件以输入框的name属性作为标志。
  3. 默认绑定的是输入框的input、propertychange事件,但是在表单元素上面添加lay-lazy属性时绑定的是blur事件

输入框/文本域限制提示

实验maxlength属性可以限制输入框能输入的最大字数,但是在页面上没有提示还能输入多少字数,这里将会新增一个提示效果。

下拉树

实验selectTree下拉树功能是将下拉选择框和tree组件结合的一个新功能。

  1. selectTree分为单选和复选,是根据设置的配置项决定的。在复选模式下formplus以数组进行维护。使用第一类取值方法能获取一个以,分隔的字符串;使用第二类取值方法能获取一个字符串数组
  2. selectTree需要额外的引入组件tree和treeorder
  3. 属性:selectTree使用lay-options属性值来指定配置项,除了支持tree的配置还包括下面的配置项:
    key 描述 默认值 名称
    id 树的id,通过这个id后面可以获取树实例,没有也会随机生成,但是还是建议自己定义一个作为区分 '-' 树的id
    data 树的数据源,与下面的url二选一,这里可以先空着填[],后面还有方法赋值 '-' 树的数据源
    url 异步获取树的数据的地址 '-' 异步请求地址
    showCheckbox 需要和layui.tree里面的这个属性区分,这里仅判断是否为复选 false 是否复选
    checkbox 复选模式下,是否阻止选择后就关闭下拉框 false 选择后收起

  4. 关于tree的实例获取:

    实验layui.formplus.$tree[id]
    • id即为tree的实例id属性,虽然没填会自动生成,但是考虑到这里的调用,建议使用属性lay-options来指定一个。
    selectTree功能会自动创建一个tree实例对象,后面需要利用这个对象来进行操作。但是tree组件除了创建返回实例后就没有再次检索这个实例的方法。formplus将这个实例的id作为key,将这个实例放在了layui.formplus.$tree下面。

  5. 关于tree的点击事件:

    实验layui.form.on('selectTree(filter)', fn)是鼠标点击tree中各个子节点的回调函数,在这里不仅可以做出一个处理逻辑,还可以通过函数的返回值控制该子节点能否选中。
    • 参数selectTree(filter)是一个特定结构;filter为元素属性lay-filter对应的值。必填。
    • 参数callback为事件执行时的回调函数,并返回一个包含各种值的object类型的参数。该回调函数返回false为阻止树选择此节点

  6. 关于selectTree的更新方法:

    实验layui.formplus.doFixValue(othis)
    • 参数othis必填,对应该下拉树的root节点,也就是class值为layui-form-select的那个dom对象(在下面的监听事件中,指代的是obj.othis)

    应用场景:

    这个方法在设计之初不存在,是为了修复下面的bug才提供出来的:

    • 首先,在功能selectTree中涉及的是一对变量值(以name属性为mytree为例),代表这个表单元素的mytree和formplus渲染后,用来展示的输入框*mytree。它们一个是form表单值,一个是页面展示值,是成对存在的。(可以想象成下拉选择框的value和select.find("option:selected").text())
    • 正常的点击事件都会触发这两个值之间的同步回调,但是在表单赋值的操作下,两者会导致不同步。
    • 一般的,再次调用layui.form.render方法可以再次强制这个两个值进行同步,但是会强制这个下拉树收起。
    • 在复选模式的下拉树选择期间,并不是选一下就要马上就要收起layui.form.render方法就不适用了,这时应该使用layui.formplus.doFixValue方法来进行参数同步。

  7. 关于selectTree的dom结构:

    需要满足下面的dom结构formplus才会以selectTree的方式进行渲染
    <div class="layui-unselect layui-form-select">
    <div class="layui-select-title"  >
        <input type="text" autocomplete="false" placeholder="placeholder" name="name" class="layui-input" lay-options="{}" lay-filter="filter" />
    </div>
</div>

            // 表单渲染
            layui.form.render(null, 'formplus-form-demo7', true);
            // 表单事件监听 - 提交事件
            layui.form.on('submit(formplus-bth-demo7)', function(obj){

            layui.formplus.on('formplus-form-demo7','tree3', function(value, oldValue){

                console.log('简单事件 - 旧值:{' + oldValue + '}, 新值: {' + value + '}');
            });
            layui.formplus.on('formplus-form-demo7','tree4', function(value, oldValue){
                layui.layer.msg('进阶事件 - 旧值:{' + oldValue + '}, 新值: {' + value + '}', {icon: 6});
                console.log('进阶事件 - 旧值:{' + oldValue + '}, 新值: {' + value + '}');
            });

            $('#formplus-bth-demo7').on('click', function(){
                let field = layui.formplus.getValue('formplus-form-demo7');
                layui.layer.msg(JSON.stringify(field), {icon: 6});
            });
            // 设置下拉树的点击事件
            // 简单事件,我们可以通过函数的返回值控制该节点是选中true还是不选中false,
            layui.form.on('selectTree(selectTree-demo03)', function(obj){
                // 仅没有子节点的节点才被选中
                var finalFlag = !obj.value.children || obj.value.children.length == 0;
                return finalFlag;
            });

            // 查找树下面所有的无子节点的节点id
            function findAllNodeId(childrens, ids = []){
                layui.each(childrens, function(key, value){
                    if(!value.children || value.children.length == 0){
                        ids.push(value.id);
                    } else {
                        findAllNodeId(value.children, ids);
                    }
                });
                return ids;
            }

            // 判断v值在数组a中的位置
            function indexOf(a, v){
                let index = -1;
                layui.each(a, function(i, a1){
                  if (a1 == v) {
                    index = i;
                  }
                });
                return index;
            }

            // 进阶事件,我们可以在这函数里面做更多的事情
            // 这里实现点击父节点选中或不选中下面的所有子节点
            layui.form.on('selectTree(selectTree-demo04)', function(obj){
                // 仅没有子节点的节点才被选中
                var finalFlag = !obj.value.children || obj.value.children.length == 0;
                if(finalFlag) return true;
                // 获取它下面所有的无子节点的节点
                var ids = findAllNodeId(obj.value.children);
                // 获取当前的树对应的值(下拉树复选的话也是对应的数组类型的数据)
                var values = layui.formplus.getValue('formplus-form-demo7', 'tree4');
                // 第一次判断,是否是全选,是就移除所有节点,否则添加所有节点
                // flag true 非全选  false 全选
                var flag = false;
                layui.each(ids, function(key, value){
                    if(indexOf(values, value) == -1) flag = true;
                });
                // 修改当前表单的值
                // 有一个问题 values 在push和splice没有改变到值,这里先使用layui.formplus.getValue('formplus-form-demo7', 'tree4')替代
                layui.each(ids, function(key, value){
                    if(indexOf(layui.formplus.getValue('formplus-form-demo7', 'tree4'), value) == -1){
                        // 不在取值范围内,如果不是全选就加入选上
                        if(flag) layui.formplus.getValue('formplus-form-demo7', 'tree4').push(value);
                    } else {
                        // 在取值范围内,如果是全选就删除取消
                        if(!flag) layui.formplus.getValue('formplus-form-demo7', 'tree4').splice(indexOf(layui.formplus.getValue('formplus-form-demo7', 'tree4'),value), 1);
                    }
                });
                // 这个方法不行,这个方式只能刷新下拉框收起的下拉树(如果是收起了,也不用这个方法,会自动刷新的)
                // layui.form.render(null, 'formplus-form-demo7', true);
                // 这个下拉树是允许连续选择的,所以调用下面的方法吧
                layui.formplus.doFixValue(obj.othis);
                return finalFlag;
            });

        });

日期渲染

实验laydate将组件laydate放入表单渲染时一起渲染。其配置参数以lay-options属性值进行设置。

  • 属性:laydate使用lay-options属性值来指定配置项,除了支持组件laydate的以下配置项以及其它可以json化的配置项:
    属性名 描述 类型 默认值
    id 设定实例唯一索引，以便用于其他方法对例进行相关操作。若该属性未设置，则默认从elem属性绑定的元素中的id属性值中获取。 String -
    type 组件面板选择类型。支持以下可选值:year、month、date、time、datetime String 'date'
    format 自定义日期和时间值的返回格式 String 'yyyy-MM-dd'
    value 初始值,lay-options只支持字符串 String '-'
    theme 主题,lay-options只支持字符串 String '-'

  • laydate只能渲染简单的时间选择框,像联动或者复杂的是不支持的。遇到这种以lay-options属性值不能搞定的情况可以采取下面的方法:

    1. 可以放弃formplus的时间管理,不添加laydate属性,这个时候formplus会将它当作普通的输入框对待。
    2. 可以在formplus渲染之前先对你的这个时间选择框使用laydate组件进行渲染,那之后再渲染整个表单即可。
    3. 最后,如果不能达到预期的效果,可以添加属性lay-formplus-ignore来进行忽略渲染

        layui.use('formplus', function(){

            // 防抖测试
            function debounce(isClear, fn = {}){
                if(layui.type(isClear) != 'function'){
                    if(fn._throttleID){
                        clearTimeout(fn._throttleID);
                    }
                } else {
                    debounce(true, isClear);
                    var param = {
                        context: fn.context || null,
                        args: fn.args || [],
                        time: fn.time || 300
                    };
                    isClear._throttleID = setTimeout(function () {
                        isClear.apply(param.context, param.args);
                    }, param.time);
                }
            }

            // 缓存原来的值
            var old = layui.form.val('formplus-bth-demo1').interest || '';

            // 表单值切换事件
            function changeSelect (value, oldValue){
                if(value != old){
                    layui.layer.msg('选择框 - 旧值:{' + oldValue + '}, 新值: {' + value + '}', {icon: 6});
                    console.log('选择框 - 旧值:{' + oldValue + '}, 新值: {' + value + '}');
                    old = value;
                }
            }

            // 表单渲染
            layui.form.render(null, 'formplus-form-demo11', true);

            // 表单事件监听 - 使用formplus添加表单监听事件
            // 可以不用自己设置lay-filter属性,防止重复或者设置不规范
            layui.formplus.on('formplus-form-demo11','interest', function(value, oldValue){
                debounce(changeSelect, {args: [value, oldValue]});
            });
            
            // 表单事件监听 - 普通点击事件
            $('#formplus-bth-demo11-change').on('click', function(){
                // 使用formplus修改表单
                layui.formplus.val('formplus-form-demo11', {'interest': '5'});
            });

            // 表单事件监听 - formplus取值
            $('#formplus-bth-demo11-val').on('click', function(){
                // 使用formplus修改表单
                // 实验性,可以直接修改表单值
                let field = layui.formplus.val('formplus-form-demo11');
                layui.layer.msg(JSON.stringify(field), {icon: 6});
            });
        });
